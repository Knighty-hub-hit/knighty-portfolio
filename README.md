# Knighty — Personal Portfolio

An English-language portfolio for Xue (Knighty) Ke, featuring AI products, business and growth projects, research, creative work, and internship experience.

Built with React, TypeScript and Vite. Responsive layout, project filtering, accessible project dialogs and reduced-motion support.

## Local development

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

GitHub Actions deploys `dist/` to GitHub Pages on pushes to `main`.

Résumé content is in `src/data.ts`; personal introduction and education are in `src/main.tsx`. Figures are self-reported from the author's résumé. Decorative graphics do not represent product screenshots.

See `使用说明.md` for Chinese documentation.
